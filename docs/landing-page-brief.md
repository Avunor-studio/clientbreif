# ClientBrief homepage creative brief

Design a calm, product-led homepage for ClientBrief. The audience is agencies that need to turn a client conversation into an agreed project handoff. The primary action is **Create a workspace**. The secondary action, **See an example**, opens a public walkthrough on the same page.

The visual direction draws on [Mobbin’s homepage](https://mobbin.com/) for centered typography, generous whitespace, clear actions, and a prominently framed product preview. From the supplied Motion Slides prompt, adapt the idea of showing source material becoming an output. Use ClientBrief screenshots, sample data and interface elements for the resulting design.

## Page layout

- Use Geist for the homepage headings and interface text. Set the page on warm white `#FAF9F6` with charcoal `#181817`, light borders, and ink blue `#3754A4` for emphasis. Keep the existing navigation and footer.
- Lead with **Turn client calls into briefs your clients can approve.** Below it, explain the recording, transcript, draft, and sharing steps in one short paragraph. Place both hero actions above the existing responsive screenshot of a sample website discovery meeting.
- Use the same sample meeting in the walkthrough and the four output tabs. Show an excerpt about building a five-page website with a contact form and the corresponding brief decision. The tabs open a project brief, decisions, action items, and a follow-up email draft.
- Explain the four steps from uploading a recording to getting client approval. Close with a practical FAQ, the existing Pricing link, and a workspace CTA. Base each product claim on the app’s current behavior.

## Motion and accessibility

Give the transcript-to-brief walkthrough one short, scroll-triggered sequence. Highlight the source phrase and move the decision card slightly into place. Keep the content readable before the animation, honor reduced-motion preferences, and show all sample outputs when JavaScript is disabled. Use responsive crops of the real workspace on desktop and mobile.
